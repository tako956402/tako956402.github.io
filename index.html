歩行テンポ連動 音楽推薦システム

スマートフォンの加速度センサーで歩行テンポ(BPM)を計測し、生成AIと楽曲データベースを組み合わせてテンポの合う楽曲を推薦・再生するシステムです。知能情報システム開発課題(レポート3)の制作物として、開発段階ごとにページを分けて公開しています。

STEP 1
歩行BPM決定
加速度センサーによる歩行テンポの自動計測(準備2歩+計測4歩)と、活動モード選択によるBPM決定。
 STEP 2
選曲エンジン(LLM推薦+実在検証)
Gemini APIによる候補曲の提案と、iTunes Search APIによる実在検証・試聴。実在しない候補(ハルシネーション)は自動棄却。
 STEP 3
選曲エンジン(外部DBテンポ検証)
GetSongBPMデータベースの実測テンポと照合し、AIの申告BPMに依存しない選曲を実現。倍/半テンポの一致判定にも対応。
 STEP 3B
選曲エンジン(逆方向パイプライン)
GetSongBPMから目標テンポの実在曲プールを先に取得し、AIは選別役に。ハルシネーションを構造的に排除する方式(比較実験用)。
 STEP 4 — 完成形
歩行テンポ連動 音楽推薦プレイヤー
歩行計測(またはモード選択)→ 4段検証つき選曲(実在・邦楽・年式・テンポ)→ 試聴の連続再生までを1画面に統合した本体アプリ。
楽曲テンポ(BPM)データ: GetSongBPM
楽曲検索・試聴音源: iTunes Search API / 候補曲生成: Google Gemini API
